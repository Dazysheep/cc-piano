# 评论透明层 alpha 提取（黑底/白底差分法）

评论透明层 alpha 提取是一种把叠加层（评论卡片与 [[cc小人]]）单独导出为带透明通道视频的技术：将同一叠加层分别绘制在黑底与白底上，用两张结果的差值反解出每个像素的透明度与颜色，从而得到可独立成轨的透明视频。

## 为什么需要

有评论故事的歌出片时，希望评论层能独立成轨、单独调整，而不是与正片焊死。为此同一帧需要同时输出三份产物：

- 成片（带评论，和以前一样）
- 不带评论的正片
- 只有评论卡片和小人的透明视频（VP9 透明通道）

## 算法

设叠加层在像素处的颜色为 C、透明度为 α：

- 黑底结果：`B_black = C · α`
- 白底结果：`B_white = C · α + (1 − α)`

由此：

- 透明度：`α = 1 − (B_white − B_black)`
- 颜色：`C = B_black ÷ α`

即“两张的差就是透明度，颜色 = 黑底结果 ÷ 透明度”。

## 为什么是精确解

叠加层只包含贴图与压暗，不含半透明混合之外的复杂运算，因此上述线性关系成立，反解是精确的。实测与直接合成相比误差不超过 2/255。

## 工程落地

剪辑工程里评论层是最上面一条轨，可以单独调整。该结论回答了 [[评论层透明通道分离是否可行]]。
