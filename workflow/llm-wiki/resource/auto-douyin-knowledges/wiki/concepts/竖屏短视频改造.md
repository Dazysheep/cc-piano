# 竖屏短视频改造

竖屏短视频改造指把原本横屏 1920×1080 的音轨视频改为竖屏 1080×1920，以适配抖音的竖屏浏览形态。本方案将其列为提升完播率的头号改造项。

## 问题诊断

- 现有音轨视频只有横屏 1920×1080（`tracks/daw.py:18`；`build.py:295` 把 `orientation` 写死成 horizontal）。
- 抖音是竖屏刷的，横屏视频在手机上只占中间一小条，被判为完播率低的头号原因（属推断性因果，尚无 A/B 证据）。

## 改造方案

- 在 `tracks/daw.py` 加竖屏布局：上方标题与封面，中间多轨面板（轨道数可减少或放大），下方歌词带与 Claude Code 小人。
- `build.py` 加 `vertical` 选项，`job.json` 按实际方向写 `orientation`。
- `tracks/flick_intro.py` 已支持竖屏，直接复用。
- 音轨类成片走竖屏，抖音用 `video_vertical.mp4`。

## 验证

- `daw-hook@v2` 出竖屏 10 秒预览，用 ffprobe 检查为 1080×1920，并抽第 0、1、3 秒画面看钩子。
