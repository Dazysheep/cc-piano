# 开头结尾小剧场（加班的夜 / 回家）

开头结尾小剧场是 cc-piano 短视频在第五轮迭代中引入的叙事型首尾结构：开头用一段「加班的夜」把观众带入办公室场景，结尾用一段「回家」收束情绪。它替代了此前单纯依赖前 3 秒钩子的开场方式，把评论区素材、双小人角色与镜头运动整合成一条完整故事线。

## 开头小剧场：加班的夜

事件序列（六段式：评论 → 场景 → 情绪 → 冲突 → 温情 → 转场）：

1. **评论浮现**：最戳人的评论（「世界上有个特别幸福的人 她正在读我这句话」）浮现在画面中间，歌响起，歌名歌手在左上角。
2. **镜头下探**：视角从半月往下拉，进入高楼办公室，男生在办公桌前读评论。
3. **情绪触发**：读到那条评论，评论浮现、很有感触，触发 [[想象云朵]]。
4. **冲突**：老板来电，电话里一直催、说乱七八糟的话，用 `！……#（@……（！&` 一类乱码气泡表现；他被说得扭头离电话很远，老板挂断。
5. **温情**：女朋友来电叫他早点回来、做了红烧肉，他哭着拉着桌上女朋友送的老虎扭蛋机。来电卡片里画出打电话的人（老板 / 女朋友），以人物形象区分来电人而非文字标注。
6. **转场**：拨片开头在右边浮现，画面从右往左拉，封面到中间，歌名从左上角移到封面下面；同时他收拾东西、关灯下班离开。

## 结尾小剧场：回家

快到结尾时中间浮现一个视频小窗：男生回家，坐在餐桌旁和女生聊天，女生用 [[网易云音乐]] 播放这首歌，手机上方浮现这首歌封面的小窗口；最后两人鞠躬，画面从远往近推直到消失。

## 三种镜头运动及其叙事功能

| 镜头运动 | 出现位置 | 叙事功能 |
|---|---|---|
| 下探（从半月往下拉） | 开头 | 进入场景 |
| 右往左拉 | 开头转场 | 封面归位、歌名移位 |
| 远往近推 | 结尾 | 收尾消失 |

## 与钩子型开头的关系

本轮开头是评论浮现 + 镜头下探 + 办公室叙事的慢起，与既有 [[前3秒钩子设计]]、[[cold-open开头直接进高潮]] 的路线形成并存关系。是否牺牲 2 秒跳出率尚无数据，见 [[84秒叙事型开头是否损害2秒跳出率]]。

## 一次性剧情道具

红烧肉、老虎扭蛋机、乱码气泡等仅服务单条视频的叙事细节，不单独建页，保留在本页与来源页中。
