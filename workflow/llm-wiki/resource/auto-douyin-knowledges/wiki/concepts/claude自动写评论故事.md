# Claude 自动写评论故事

## 是什么

Claude 自动写评论故事指用 [[claude-code]] 的**无界面（非交互）模式**，在定时任务中读取录屏评论区内容，自动生成结构化的评论故事文件 `story.json`，并附带开头评论、标题文案与话题。它是 cc-piano 的 daily-make 任务中的核心「思考步骤」。

## 成本

每次约 1 分钟、约 0.5 美元。实测两次：0.48 与 0.51 美元。样本量小（n=2）但数值一致，可信度较高；未说明是否包含修正轮次的额外开销。

## 安全限制（三重）

1. **工具白名单**：Claude 只能用 Read / Write 工具。
2. **目录隔离**：只在 `workflow/data/story/<录屏名>/` 里工作。
3. **不加载项目设置**：不加载项目 hooks 与 MCP。

这三重限制体现权限最小化思路，与 [[机械步骤与思考步骤分层]] 的边界设计一致。

## 输出与校验

写出的 `story.json` 交由 `daily_make.check_story` 按白名单校验，不合格先修一次，仍不合格则不出片，见 [[生成结果白名单校验与一次修正]]。转写准确性另由 [[逐字照抄约束]] 约束。
