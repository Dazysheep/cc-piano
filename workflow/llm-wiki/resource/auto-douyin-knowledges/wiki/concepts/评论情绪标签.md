# 评论情绪标签（mood 字段）

评论情绪标签是 story 卡片上的 `mood` 字段，用于驱动 [[cc小人]] 在 [[评论舞台]] 上选择对应的情绪动作。它是评论故事动画中「按评论内容表达情绪」这一环节的数据接口。

## rifle 的逐条映射

| 评论 | mood |
|------|------|
| 格子衫 | 怀念 |
| 火药受潮哈哈 | 大笑 |
| 文案淹没 | 害羞 |
| 孤独 | 孤独 |
| 普通生活也是努力经营 | 生气（带点委屈的可爱） |

| 在一起 | 心动 |
| 县城 | 怀念 |
| 23 岁小幸福 | 开心 |
| 细小的美好 | 希望 |
| 下个夏天 | 开心 |

## 与既有情绪主题分类的关系

[[rifle评论区八类情绪主题]] 将评论区归为八类情绪主题，而 CC 小人动画库提供 9 种情绪动作。两者粒度是否一致、是否需要统一，是开放问题。

## 风险

情绪映射为创作者主观判断（例如「普通生活也是努力经营 → 生气（带点委屈的可爱）」），无观众验证，存在误读评论情绪的风险。
