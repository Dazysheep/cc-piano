# Claude 作者身份钩子

Claude 作者身份钩子指在标题或开头明示「内容由 Claude 生成 / 参与」，把 AI 作者身份本身当作点击与评论动机的一种短视频钩子手法。

## 来源中的证据

- 标题范式：「一句话让 Claude 花 X 亿 token 做的 MV」「Claude 花了 30 亿 token」。
- 千本樱 MV（BV16MJY6yEKq，4:13）90.6 万播放，点赞率 18.9% / 收藏率 9.3% / 分享率 1.74%，评论 6615。
- 爱丽丝 MV（BV11unF6fEmq，3:33）7.2 万播放，点赞率 30.1% / 收藏率 13.1% / 分享率 1.74%。
- 《Claude Opus 5.5の小曲》（2:15）40.4 万播放，点赞率 12.7% / 收藏率 15.6% / 分享率 0.29%，属「Claude 的小曲」梗文化。
- 评论区在感叹「能做到这种程度」，并玩「Claude 叔叔 / 克劳德」的梗。

## 与自家内容的关系

自家视频本来就是 Claude 读评论、拆音轨做出来的，但标题和开头没说出来。来源建议在标题 / 开头写明「Claude」，例如「我让 Claude 翻完了这首歌的评论区」「Claude 拆开这首歌，发现是写给父亲的」。

## 诚信约束

只写真实做过的事，不编 token 数、不编评论数。这是来源明确写下的边界，避免钩子退化为虚假承诺。

## 待验证与风险

- 该建议在来源中标注「待验证」，尚未在抖音做 A/B。
- 梗文化（Claude 叔叔、小曲）衰减快，来源未评估窗口期。
- 若抖音观众对「Claude」认知度更低，钩子是否仍成立仍属开放问题。
- 与 [[前3秒钩子设计]]、[[歌名反差钩子]] 同族，但侧重「作者身份」而非「歌名反差」。
