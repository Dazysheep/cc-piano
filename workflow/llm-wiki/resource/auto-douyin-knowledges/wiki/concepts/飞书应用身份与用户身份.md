# 飞书应用身份与用户身份

飞书 OpenAPI 的调用有两种鉴权身份，[[lark-openapi-mcp]] 对两者都提供支持。

## 应用身份（tenant_access_token）

默认模式。以企业自建应用的身份调用接口，只需 App ID 与 App Secret，无需用户登录。

## 用户身份（user_access_token）

以具体用户身份调用接口，需要先走 OAuth 登录：

```
npx -y @larksuiteoapi/lark-mcp login -a … -s …
```

- 回调地址：`http://localhost:3000/callback`
- 运行时需加参数：`--oauth --token-mode user_access_token`

## 选择考量

在阶段 B 中需确定用应用身份还是个人身份发消息。应用身份配置更简单；用户身份更贴近个人视角，但需要 OAuth 登录流程与本地回调。

## 相关安全实践

App Secret 应通过环境变量注入，不写入命令参数或项目文件。
