# 动画库 LLM 方案生成与字段校验

动画库 LLM 方案生成与字段校验是 cc-piano 动画库模块的编辑流程设计：用户通过聊天框配置自己的大模型，模型只返回 JSON 方案，服务端按字段说明做机械校验，用户点「采用」后才存成新版本并渲染预览。

## 素材规格

- 表情（男 / 女）、想象画面都存成沿人物边缘裁好的透明 webp（例如 360×300 的画布裁成约 200×195），而非整幅画布。
- 开头 / 结尾动画存预览视频。

## 编辑流程

1. 每个可编辑条目有聊天框，用户配置自己的大模型（OpenAI 兼容接口）。
2. 模型只能返回 JSON 方案。
3. 服务端按字段说明检查：未知字段丢掉、数值夹在范围内、枚举值必须合法。
4. 用户点「采用」才存成新版本并渲染预览。

## 安全边界

密钥只存在用户环境变量 `CC_PIANO_LLM_KEY`，不进入代码或配置仓库。

## 设计缺口

字段校验能保证结构合法，但不能保证语义合理（例如合法枚举但情绪不匹配），这是已知缺口。

## 与既有概念的关系

- 「采用才存新版本」与 [[模板库版本化]]、[[剪辑自动存版与回退]] 同源。
- LLM 只出 JSON、服务端做机械校验、人来点采用，是 [[机械步骤与思考步骤分层]] 的清晰实例。
- 透明 webp 沿人物边缘裁切与 [[评论透明层alpha提取]] 同属透明素材处理，但方法不同（轮廓裁切 vs 黑底/白底差分提取）。
