# 中文路径编码坑（GBK/UTF-8）

中文路径编码坑是指在 Git Bash 中用 curl 发送含中文的路径时，路径会被转成 GBK 编码，导致服务端解析失败的问题。

## 现象与规避

- 现象：Git Bash 里用 curl 发中文路径会变成 GBK 编码。
- 规避：测试服务时改用 Python 发送 UTF-8 请求。
- 浏览器不受影响（浏览器按 UTF-8 发送）。

## 适用范围

该坑属于通用工具链问题，可能影响任何在 Windows + Git Bash 环境下用 curl 调试含中文路径接口的场景。
