# 首帧即内容

首帧即内容指视频第一帧就呈现满屏画面或完整信息，不做黑场淡入、不做延迟淡入，让观众在 0 秒即获得视觉信息的一种开头设计原则。

## 来源中的两条具体做法

1. **第一帧就有画面**：千本樱 MV 第 1 秒是水墨梅花 + 满月（与自家半月开头同一类），P(DOOM) 第 1 秒是幕布舞台 + 大字，均无黑场淡入。
2. **第一帧就有评论**：开头那条评论现在 0.8 秒淡入，建议改成第一帧就完整显示，月亮在后面慢慢亮。该条直接对应 2 秒跳出 41% 的问题。

## 与既有概念的区别

- [[cold-open开头直接进高潮]] 讲的是声音 / 内容直接进高潮；首帧即内容讲的是视觉首帧与信息首帧，二者可叠加使用。
- [[评论舞台]] 与 [[评论半露悬念]] 描述评论如何呈现；首帧即内容描述评论呈现的**时序**——从 0.8 秒淡入提前到第 0 帧。

## 待验证

两条建议在来源中均标注「待验证」，尚未做 A/B。相关既有结论见 [[2秒跳出率是主要流失点]]。
