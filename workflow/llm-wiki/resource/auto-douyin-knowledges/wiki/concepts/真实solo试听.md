# 真实 Solo 试听

真实 Solo 试听指在音轨拆解类视频中，让某一条音轨的 Solo（S）按钮亮起、其他轨变暗，并且**声音真的只播放该轨** 2~4 小节，让观众亲耳听到「拆开了什么」的做法。

## 来源中的标杆

- 周杰伦「只听人声你就亏了」：101.7 万播放（合集 224 万），点赞率 2.7% / 收藏率 1.9% / 分享率 1.16%。做法是逐组 Solo（Fx 组 → 基础乐器组 → 人声），标题承诺「你没听到的东西」。
- A 妹 Positions 编曲解构（2:51）：16.7 万播放，点赞率 6.4% / 收藏率 2.3%，属短音轨拆解样本。

## 具体做法（来源建议）

在故事里挑 2~3 处，让一条音轨的 S 按钮亮起、其他轨变暗，声音也真的只放这一轨 2~4 小节，标签写「只听贝斯」。

## 为什么重要

来源指出自家现在「画了音轨，但声音一直是混好的成品，观众听不出拆了什么」。真实 Solo 试听依赖已有分离好的音轨，是「别人做不了、自家做得了」的差异化能力，也是 [[音轨拆解式内容]] 从「画音轨」升级为「听音轨」的关键一步。
