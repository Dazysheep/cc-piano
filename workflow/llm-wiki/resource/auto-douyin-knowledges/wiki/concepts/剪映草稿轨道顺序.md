# 剪映草稿轨道顺序

剪映草稿轨道顺序指 [[cc-piano琴房-studio]] 通过 [[pyjianyingdraft]] 生成可编辑剪映草稿时，各素材层在时间线上的叠放次序。轨道顺序决定了画面合成结果，是「成片可继续在剪映里编辑」这一交付形态的结构化约定。

## 轨道叠放次序（从下到上）

| 层级 | 轨道 | 说明 |
|---|---|---|
| 1（最底） | 背景 | 背景图/视频或深色渐变 |
| 2 | 音符 | 黑底下落音符层，混合模式为滤色（screen） |
| 3 | 琴键 | 琴键条图层 |
| 4 | 蒙版 | 文字保护/压暗蒙版 `scrim.png` |
| 5 | 片头 | 爆款开头（`intro.enabled` 默认关闭，开启时存在） |
| 6 | 标题 | 标题文字层 |
| 7 | 副标题 | 副标题文字层 |
| 8 | 水印 | 水印署名 |
| 9 | 钢琴 | 钢琴声音轨 |
| 10（最上） | 背景音 | 背景音乐音轨 |

## 生成与落盘流程

1. 草稿先写到 `output/<曲名>/draft/`。
2. 再用 robocopy 镜像进剪映草稿目录——因为商店版 Python 不能直接写 AppData。
3. 草稿引用 `output/<曲名>/<时间戳>/` 里的素材，**导出前不能删**这些中间素材。

## 注意事项

- 片头轨道仅在开启爆款开头时存在；`config.yaml` 中 `intro.enabled: false` 为默认状态，代码保留。
- 预览模式（`--preview`）不生成草稿，只写 `output/<曲名>/preview.mp4`。
- 本文档未实测完整成片 + 剪映草稿的生成，轨道顺序结论来自源码阅读。
