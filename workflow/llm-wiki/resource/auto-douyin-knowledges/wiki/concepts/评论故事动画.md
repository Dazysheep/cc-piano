# 评论故事动画（CommentStory）

评论故事动画是一种把评论区留言转化为视频叙事的动画机制：每条评论从它对应音轨的播放头处「长出」，沿弧线飘移、逐行显现、停留后上飘，最终在尾声汇入专辑封面。它把零散的评论碎片组织成有起伏的完整叙事，是 [[评论区作为内容素材]] 从文案走向画面的实现方式。

## 实现位置

- 动画类：`douyin/tracks/stage.py` 的 `CommentStory`
- 数据：歌曲 json 的 `story` 字段（幕 → 卡片）
- 调度：`douyin/tracks/build.py` 的 `schedule_story`，把卡片出现时刻吸附到重拍（与 [[卡点截取与节拍吸附]] 同源）

## 机制

- 每条评论从它对应音轨的播放头处「长」出来，带一条从音轨连过去的光线。
- 评论沿弧线飘到那条音轨旁边停住，文字逐行显现，停留后向上飘走。
- 安静的一幕一次只出现一条大字「独白」，画面同时微微压暗聚焦。
- 高潮的一幕多条碎片同时浮现。
- 尾声：所有还在画面上的评论像拼图一样飞进专辑封面，最后一句话淡入，再接首尾循环转场。

## rifle 的五幕时间轴

按音乐起伏切幕（0–17 秒响、18–38 秒安静、39–55 秒推向高潮），详见 [[分幕结构]]：

| 幕 | 时间 | 内容 |
|----|------|------|
| 序幕 | 0–6 秒 | 钩子「这首歌叫步枪，第一枪打中的是十六岁」→ 拨片开头 → 水墨转场 |
| 上膛 | 6–17 秒 | 格子衫和 mp3；「我也会变成一支上膛的步枪，可火药受潮了，哈哈」；「评论区被文案淹没，可这就是青春」 |
| 哑火 | 18–38 秒（独白） | 孤独 → 普通也是努力经营的 → 牵爸爸妈妈的手 → 最后一发子弹叫思念 |
| 拼图 | 39–55 秒 | 高考倒计时、和喜欢的人在一起、县城、23 岁的小幸福、细小的美好、下个夏天再见 |
| 尾声 | 55–58 秒 | 「愿你找到缺的那一块 / I hope you can find the missing piece」 |

## 设计原则

- 评论需**改写**后使用，不出现用户名，不直接引用他人具体伤痛经历（见 [[去标识化与不消费他人伤痛]]）。
- 评论与音轨画面同时亮起，使「单条评论 ↔ 单条音轨」的对应关系可被观众感知，呼应 [[音轨拆解式内容]]。
