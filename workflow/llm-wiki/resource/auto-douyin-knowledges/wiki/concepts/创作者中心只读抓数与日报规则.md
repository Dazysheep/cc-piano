# 创作者中心只读抓数与日报规则

创作者中心只读抓数与日报规则是 cc-piano 的数据自动化模块：复用发布台已登录的浏览器资料，以 Edge 无界面模式只读访问抖音创作者中心的作品列表与指标接口，将快照落盘，并每天 12:00 按硬编码阈值生成问题与建议。

## 抓数方式

- 复用发布台登录过的浏览器资料（profile）
- Edge 无界面模式（headless）只读访问
- 快照存在 `workflow/data/creator/`

## 接口与字段

- 作品列表接口：`janus/douyin/creator/pc/work_list`
- 每条作品的完整指标：`web/api/creator/item/mget?ids=…&fields=metrics`

指标字段集：

| 字段 | 含义 |
|---|---|
| `completion_rate` | 完播率 |
| `completion_rate_5s` | 5 秒完播 |
| `bounce_rate_2s` | 2 秒跳出 |
| `avg_view_second` | 平均观看秒数 |
| `avg_view_proportion` | 看完全片比例 |
| 点赞率 | 点赞率 |
| 收藏 | 收藏 |
| `subscribe_count` | 涨粉 |

## 日报规则

每天 12:00 与前一天的快照对比；问题和建议按写死的规则从数字推出，阈值：

- 2 秒跳出 > 40%
- 5 秒完播 < 30%
- 看完全片 < 15%

所有建议统一标注「待验证」。

## 待确认

日报阈值与当前实测（2 秒跳出 41.1%）几乎贴线，规则可能频繁触发告警，阈值是否应改为相对变化而非绝对值仍待验证。

该模块遵循 [[只读抓数与数据诚信]] 原则，并受 [[playwright-profile互斥]] 约束；周报侧见 [[周报ppt自动化]]。
