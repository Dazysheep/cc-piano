# 单变量短视频实验法

单变量短视频实验法是一种用于验证短视频改动效果的实验设计：一次只改一个变量，每个变量持续 2–3 天，用完播率与 2 秒跳出率对比前后表现。

## 为什么这样做

短视频的完播率受选题、封面、账号权重、发布时间等多因素影响。若同时改动多个变量，无法判断效果来自哪一项。单变量法把因果归因的难度降到最低。

## 具体做法

- 基线：`daw-classic@v1`（横屏），用上周数据。
- 每个实验版本存为新的模板版本（v2、v3……），旧版本永不覆盖，详见 [[模板库版本化]]。
- 每个变量持续 2–3 天，用完播率与 2 秒跳出率对比。
- 实验记录写入 `workflow/experiments/round1.md`，同步到知识库。

## 第一轮实验设计

- 基线 `daw-classic@v1`：横屏，上周数据。
- `daw-hook@v2` = v1 + 竖屏 + 开头直接进副歌 + 第一帧就有声音 + 0–3 秒钩子文字 + 缩短的拨片开头（结尾保留 Claude Code 小人和拨片元素）。

## 已知张力

方案第 1 步把竖屏与钩子**打包**进 v2，与「一次只改一个变量」原则自相矛盾。是否拆成 v2 竖屏 / v3 钩子两轮，属待用户确认的开放问题。相关讨论见 [[竖屏短视频改造]]、[[前3秒钩子设计]]。
