# cc-piano 完整成片与剪映草稿是否可用？

## 问题

[[cc-piano琴房-studio]] 的若干支线流程在 2026-10-24 的试跑中**未被实测**，相关结论仅来自源码阅读。需要验证这些流程在真实环境下是否可用、产物是否符合预期。

## 未实测清单

1. **完整成片 + 剪映草稿**：完整时长渲染、[[剪映草稿轨道顺序]] 是否正确、草稿在剪映中能否打开并继续编辑（尤其商店版 Python 下 robocopy 镜像的兼容边界）。
2. **音轨剪辑**：[[demucs]] `htdemucs_6s` 六轨分离、波形滚动、[[faster-whisper]] 歌词识别与 LRC 纠错的实际效果。
3. **拨片开头**：`tracks/flick_render.py` 的 4 秒开头（约 5–7 分钟）与剪映草稿。
4. **录音转写**：mp3/wav → MIDI 的钢琴转写模型效果。
5. **发布台**：专用 Edge 逐平台填表、停在「发布」按钮前的人工确认流程；各平台选择器稳定性与改版频率。
