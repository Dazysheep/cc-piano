# 平均观看时长占比应按条均还是加权计算？

## 问题

[[抖音日报-2026-10-27]] 正文称「平均每人只看 9.6 秒（作品平均 150 秒，看了 8%）」，但 9.6 / 150 ≈ **6.4%**，与 8% 不符。

## 两种可能口径

1. **比值口径**：条均平均观看秒数 ÷ 条均片长 = 9.6 / 150 ≈ 6.4%。
2. **逐条占比算术平均**：各条「平均观看 / 时长」再取均值：
   - 6.0/84 = 7.1%
   - 4.9/60 = 8.2%
   - 6.7/87 = 7.7%
   - 18.1/100 = 18.1%
   - 4.8/102 = 4.7%
   - 11.1/345 = 3.2%
   - 15.5/274 = 5.7%
   - 均值 ≈ **7.8% ≈ 8%**

第二种口径能复现 8%，但会让短作品与长作品等权，可能高估整体观看深度。

## 待确认

- 数据源（[[抖音创作者中心]]）实际采用哪种口径？
- 若采用逐条算术平均，是否应在日报中显式标注，避免与「总观看时长 / 总播放」的加权口径混淆？
