# cc-piano 第二轮改造：开头去字、CC 小人读评论、OpenFilm 剪辑页（2026-10-24）

本文件是 [[cc-piano琴房-studio]] 项目第二轮改造的工作记录，承接《[[rifle歌曲]]》评论故事版首轮成片后的用户反馈。记录包含四项改造（模板 daw@v4、CC 小人动画库 v1、评论舞台、OpenFilm 剪辑页）、三个技术坑与两项待办。属于项目内部实施记录，但其中若干设计决策与可复用组件具备独立知识价值。

## 用户反馈（看完《rifle》评论故事版之后）

1. 开头的文字全部去掉，只留拨片开头；开头主图用拨片图库里的 rifle（027.jpg）。
2. CC 小人没出现（原因：唱歌小人只在有 LRC 歌词时才出场，rifle 没有歌词文件）。
3. 要「网易云评论」文件夹，小人从文件夹拿出评论、读、评论浮现、按评论内容表达情绪；动画要多变立体，并单独保存方便以后优化。
4. 接入 OpenFilm，以后剪辑都在 cc-piano 里做，提供用户剪辑，并保留所有剪辑过程。

## 做了什么

### 模板 daw@v4

v3 + 开头不写任何文字。图库主图用 `intro_final` 指定；每日制作按「歌名 - 歌手」自动匹配图库（OCR 常把 vs. 认成 VS.，只比字母数字）。详见 [[daw模板]] 与 [[录屏素材管线与歌名识别]]。

### CC 小人动画库 v1（`tracks/clawd_anim.py`）

立体像素小人——身体有顶面（亮）和右侧面（暗）的厚度，像等距积木；起跳拉长、落地压扁；转身用水平缩放；走近镜头整体放大；脚下软阴影随跳高变小变淡。17 段动画：待机、走路、转身、走近镜头、开文件夹、抽评论、读评论（眼睛左右扫）、抛评论，以及 9 种情绪：难过（掉泪）、孤独（抱膝坐着摇）、开心（蹦跳+星光）、心动（爱心眼+飘爱心）、希望（握拳抬头）、大笑（前仰后合）、怀念（抬头望天+音符）、生气（跺脚冒气）、害羞（捂脸+汗滴）。每段导出透明 webm / gif / png，预览页 `douyin/assets/clawd/animations/index.html`。详见 [[cc小人]]。

### 评论舞台（`tracks/comment_scene.py`）

底部 210 像素舞台；右侧红色「网易云评论」文件夹（自己画的红底白音符图标，不用官方 logo 文件）。每条评论：走到文件夹 → 打开 → 抽出纸 → 读 → 抛起，纸飞上去展开成评论卡片，飞到对应音轨旁 → 小人做这条评论的情绪动作；独白卡片时小人走到舞台中间，背景压暗但小人不暗。卡片密的时候自动压缩取评论的动作（最多压到 45%），保证每段情绪至少 1.3 秒（独白 2 秒）。尾声卡片飞回文件夹，小人抬头看最后一句。详见 [[评论舞台]] 与 [[评论故事动画]]。

### OpenFilm 剪辑页

[[openfilm]] 0.2.5（MIT）装在 `douyin/editor/`；剪辑器能嵌入别的程序（它专门不设 frame-ancestors，还设了给嵌入用的 cookie）。数据、工程、渲染用的浏览器都放在 D 盘，ffmpeg/ffprobe 用项目里的 `tools/ffmpeg`。成片自动生成 `film/film.html` 工程（素材硬链接不占空间；音乐音量按实测响度调到和成片一样的 -14 LUFS）。每一次剪辑改动都自动存一版（`film/.cc-history/`），可以回到任何一步，恢复本身也记一步。详见 [[剪辑自动存版与回退]]、[[响度对齐]]、[[素材硬链接工程]]。

## 踩过的坑

- 帧数取整后正片文件比计算长度短几毫秒，OpenFilm 严格检查会报错；改为读取文件实际时长。
- [[剪映]] 草稿的音频素材不能带画面，录屏要先只提取声音（之前已修）。
- Git Bash 里用 curl 发中文路径会变成 GBK 编码，测试服务时要用 Python 发 UTF-8；浏览器不受影响。详见 [[中文路径编码坑]]。

## 待办

- 评论卡片层单独输出带透明通道的视频，放进 OpenFilm 工程，方便在剪辑器里单独调整（现在评论烧在正片里）。
- 从剪辑器导出的成片（`video_edited.mp4`）让发布台优先使用。详见 [[发布台人工把关]]。

## 关键结论与张力

- 唱歌小人缺席的根因是 LRC 依赖：CC 小人只在有 LRC 歌词时出场，rifle 无歌词文件，故首轮未出现。
- 本轮一次性改动开头、角色、评论舞台、剪辑流程四项，无法归因效果，与 [[单变量短视频实验法]] 存在张力。
- 情绪映射（如「普通生活也是努力经营 → 生气（带点委屈的可爱）」）为创作者判断，无观众验证，存在误读评论情绪的风险。
- 自绘「网易云评论」图标刻意不用官方 logo，规避品牌风险，但可能降低识别度。
- 帧数取整坑可能影响所有依赖时长计算的环节，文件只记录了 OpenFilm 一处。
