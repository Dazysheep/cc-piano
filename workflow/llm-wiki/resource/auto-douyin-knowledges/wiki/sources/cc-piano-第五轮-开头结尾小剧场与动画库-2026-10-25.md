# cc-piano 第五轮：开头 / 结尾小剧场、动画库与聊天设计（2026-10-25）

本文件是 [[cc-piano琴房-studio]] 项目第五轮迭代的设计记录，重心从工程层转向**内容层**：用户亲自设计了开头「加班的夜」与结尾「回家」两段小剧场，并由此引出女生动画「抽搐」的根因修复、鞠躬动作重做、时长定为约 80 秒（实际 84 秒）；同时提出新产品模块「动画库」，含透明 webp 素材、预览视频，以及带 LLM 聊天框的 JSON 方案生成与校验流程。

## 开头小剧场（加班的夜）

用户选定的最戳人评论是「世界上有个特别幸福的人 她正在读我这句话」。事件序列如下：

1. 评论浮现在画面中间，歌响起，歌名歌手在左上角。
2. 视角从半月往下拉，进到高楼办公室，男生在办公桌前读评论。
3. 读到那条评论，评论浮现、很有感触（触发 [[想象云朵]]）。
4. 老板来电，电话里一直催、说乱七八糟的话（用 `！……#（@……（！&` 这样的乱码气泡表现），他被说得扭头离电话很远，老板挂断。
5. 他很难受，女朋友来电叫他早点回来、做了红烧肉，他哭着拉着桌上女朋友送的老虎扭蛋机。来电卡片里画出打电话的人（老板 / 女朋友）。
6. 拨片开头在右边浮现，画面从右往左拉，封面到中间，歌名从左上角移到封面下面；同时他收拾东西、关灯下班离开。

结构上可概括为「评论 → 场景 → 情绪 → 冲突 → 温情 → 转场」六段式。详见 [[开头结尾小剧场]]。

## 结尾小剧场（回家）

快到结尾时中间浮现一个视频小窗：男生回家，坐在餐桌旁和女生聊天，女生用 [[网易云音乐]] 播放这首歌，手机上方浮现这首歌封面的小窗口；最后两人鞠躬，画面从远往近推直到消失。音轨删减到 4 条，给小人动画腾地方。

## 其他改动

- 女生眼睛改回黑色。
- 女生唱歌动作「抽搐」的成因与修复：嘴型每帧跟着原始音量变、踮脚在节拍点上瞬间跳起、举手在音量阈值附近来回切、音符数量随音量变（音符位置会跳）。改成：嘴型 0.11 秒才换一次（音量取 ±0.08 秒平均）、踮脚用正弦慢慢起落、举手用 0.4 秒一换的慢音量、音符固定两个、进出副歌时摇摆幅度 0.6 秒平滑过渡。详见 [[动画抽搐的逐帧跟随根因]]。
- 鞠躬改成面向观众（往下一沉 + 闭眼 + 微微前倾），原来的侧倒像要摔倒。
- 视频时长：用户选约 80 秒（实际 84 秒），音乐从歌曲开头「I just need someone…」开始。

## 动画库（cc-piano 新页面）

- 表情（男 / 女）、想象画面都存成沿人物边缘裁好的透明 webp（例如 360×300 的画布裁成约 200×195），开头 / 结尾动画存预览视频。
- 每个可编辑的条目有聊天框：用户配置自己的大模型（OpenAI 兼容），模型只能返回 JSON 方案；服务端按字段说明检查（未知字段丢掉、数值夹在范围内、枚举值必须合法），用户点「采用」才存成新版本并渲染预览。密钥只存在用户环境变量 `CC_PIANO_LLM_KEY`。

详见 [[动画库llm方案生成与字段校验]]。
