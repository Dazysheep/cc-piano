# Claude Code

Claude Code 是 Anthropic 推出的命令行 AI 编程代理工具（此为可独立核实的公开背景信息，非本来源独有）。在本方案中，它以非交互方式承担流水线中「需要思考」的步骤。

## 本方案中的用法

- **非交互调用**：`claude -p "<提示词文件>"`，工作目录 `D:\cc-engine`。
- **工具白名单**：允许使用的工具在 `.claude/settings.json` 里白名单化，避免无人值守时卡在权限确认上。
- **能力来源**：这样它能用 LLM Wiki MCP、[[lark-cli]] 和 pptx 等技能。
- **承担的任务**：写日报分析、学习笔记、周报内容、改热点词/标题与话题。
- **成本**：非交互调用会消耗用户额度。

## 与机械步骤的分工

方案把「抓数据、渲染、打开发布页、发飞书消息」等纯机械步骤交给普通 Python 脚本，不消耗模型调用；只有需要判断与写作的步骤才走 Claude Code。详见 [[机械步骤与思考步骤分层]]。
