# 女生小人

女生小人是 cc-piano 音轨视频中的第二个 Claude 小人角色，位于画面左下角负责唱歌，与负责读评论的男生 [[cc小人]] 构成「唱—读」双线。她是第四轮改造新增的角色，外观与动画均独立于男生小人。

## 外观规格

- 粉色蝴蝶结。
- 睫毛：外侧水平一格；往上翘会像皱眉，属于易回归的细节坑。
- 蓝色瞳孔 + 高光。
- 常带腮红。
- 整体比之前的单一小人更小。

## 动画清单

女生专属动画：

- `sing`
- `sing_enjoy`
- `sing_loud`
- `nod`
- `wave`

与男生共用：

- `walk_happy`
- `bow`

唱歌姿态由人声音量、节拍、副歌实时驱动，与 [[concepts/beatpulse画面律动]]、[[卡点截取与节拍吸附]] 的节拍体系同源。动画要求「灵动但不转身」：摇头、闭眼享受音乐，音符持续出现。

## 资产组织约定

每个小人的表情动画单独存放（分文件），便于后续扩展与替换。
