# lark-cli

lark-cli 是一个用于操作飞书（Lark）的命令行工具，在本方案中承担发送消息、下载群文件、新建文档等飞书侧操作。它支持以「用户身份」登录（对应应用 `cli_aa58…`），从而以个人授权身份访问群消息与资源。

## 在本方案中的用途

- **发消息 / 卡片**：作为 `workflow/notify.py` 的底层调用，向「抖音运营」内部群发送通知、日报摘要、审核消息。
- **上传文件**：上传视频、PPT 等文件到群。
- **新建文档**：生成飞书文档承载日报、周报。
- **读群消息**：`lark-cli im +chat-messages-list` 拉取群消息，`+messages-resources-download` 下载群内视频/音频资源，用于收件箱机制。

## 使用约束

- 直接调用 exe；文件参数需先 `cd` 到文件所在目录（遵循 CLAUDE.md 约定）。
- 机器人身份读群消息实测报错 230027（飞书跨组织限制 / 权限不足），需改用用户身份并勾选 `im:message.group_msg:get_as_user` 权限，或在开发者后台给机器人加「获取群组中所有消息」权限。
- 个人授权已过期，需用户重新扫码登录一次。
