# 飞书（Lark）

飞书是字节跳动旗下的企业协作平台（此为可独立核实的公开背景信息，非本来源独有）。在本方案中，飞书是全部通知、文件、日报、周报的唯一通道，内部群「抖音运营」为枢纽。

## 本方案中的角色

- **通知出口**：所有通知、报表、PPT 都发到「抖音运营」群；日报生成飞书文档并私聊发摘要。
- **文件通道**：视频、封面、PPT 通过飞书上传；iPhone 上能直接打开 .pptx。
- **录屏入口**：用户从 iPhone「相册 → 分享 → 飞书 → 抖音运营群」发送录屏，程序从群里收取。
- **知识库同步**：日报、学习笔记、周报同时写入 [[llm-wiki]]。

## 「抖音运营」群

内部群，用户本人 + 机器人（机器人是管理员，用户是群主），可再拉同组织的人。群 ID `oc_63d0c14e3f625b0076518dc23bc6f8dc`，记在 `workflow/config.json`，测试消息已发出。它兼作通知出口与录屏收件入口。

## 跨组织限制

外部群「The First Step」因飞书跨组织限制报 230027 而弃用。详见 [[飞书跨组织限制230027]]。若用户以后要把内容转到外部群，就在群里手动转发。

## 权限问题

机器人读群消息实测报 230027，需用户身份或后台加权限。详见 [[机器人能否读取抖音运营群消息]]。

## 工具

飞书操作通过 [[lark-cli]] 完成，封装在 `workflow/notify.py`。
