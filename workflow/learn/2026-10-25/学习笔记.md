## 看出来的规律
1. **「Claude 做的」本身就是钩子**：标题直接写「一句话让 Claude……」「Claude 花了 30 亿 token」，评论区在感叹能做到这种程度、
   在玩「Claude 叔叔 / 克劳德」的梗。我们的视频本来就是 Claude 读评论、拆音轨做出来的，但标题和开头没说出来。
2. **我们的小人方向是对的**：P(DOOM) 用的就是同一个 Claude Code 像素小人，还有粉色蝴蝶结、戴高帽的变体，结尾一群角色在幕布舞台鞠躬——
   和我们刚做的女生小人、爸爸、结尾鞠躬几乎一致，分享率 3.11%（我们几乎没有分享）。
3. **开头 1 秒就是满屏的画**：千本樱第 1 秒是水墨梅花 + 满月（和我们的半月开头同一类），P(DOOM) 第 1 秒是幕布舞台 + 大字。
   没有黑场淡入，第一帧就有内容。
4. **音轨拆解爆的是「只听 X 你就亏了」**：逐组 Solo 给观众听（Fx 组 → 基础乐器组 → 人声），标题承诺「你没听到的东西」。
   我们现在画了音轨，但声音一直是混好的成品，观众听不出拆了什么。
5. **网易云热评是长期流量池**：「评论最多 TOPxx」这类合集几百万播放，热门评论区是大家在接龙歌名、留言。

## 改进建议（都在现有模板上改，不照抄，保持音轨主题）
1. **标题 / 开头写明「Claude」**（待验证）：比如「我让 Claude 翻完了这首歌的评论区」「Claude 拆开这首歌，发现是写给父亲的」。
   只写真实做过的事（不编 token 数、不编评论数）。
2. **第一帧就有评论**（待验证，对应 2 秒跳出 41%）：开头那条评论现在 0.8 秒淡入，改成第一帧就完整显示，月亮在后面慢慢亮。
3. **真正的「Solo」时刻**（待验证，最像「只听人声你就亏了」）：我们有分离好的音轨，故事里挑 2~3 处，
   让一条音轨的 S（Solo）按钮亮起、其他轨变暗，**声音也真的只放这一轨** 2~4 小节，标签写「只听贝斯」。这是别人做不了、我们做得了的。
4. **结尾留一个问题引评论**（待验证）：比如「你的那一块是什么？」，学网易云热评区的接龙氛围。
5. **话题**：`网易云音乐`、`编曲`、`Claude`、`AI音乐`、`歌单`（已写入 `workflow/learn/hotwords.json`，发布时补位用）。
